## Part 1: Understanding Anomaly Detection

### What is Anomaly Detection?

Anomaly detection identifies data points that deviate significantly from normal patterns. In the context of commits, an anomaly might be:

- **Massive commits**: 5000+ lines changed
- **Unusual timing**: Commits at 3 AM
- **High churn**: 90% of code deleted and rewritten
- **Too many files**: 150+ files changed at once

### Why Detect Anomalous Commits?

1. **Security**: Detect potential malicious code injection
2. **Quality**: Flag commits that need extra review
3. **Process**: Identify when developers need help
4. **Learning**: Understand what "normal" looks like

### What is Isolation Forest?

Isolation Forest is an unsupervised machine learning algorithm that:

1. **Builds random trees**: Creates decision trees with random splits
2. **Isolates anomalies**: Anomalies are easier to isolate (fewer splits needed)
3. **Scores data points**: Shorter path = more anomalous

**Key Concept:**
- Normal points are "deep" in the tree (many splits to isolate)
- Anomalous points are "shallow" (few splits to isolate)

**Example:**
```
Normal commit: 100 lines, 5 files, 2pm
- Split 1: lines < 1000? Yes
- Split 2: files < 50? Yes
- Split 3: hour < 20? Yes
- Split 4: lines > 50? Yes
- Split 5: files > 2? Yes
→ Path length: 5 (normal)

Anomalous commit: 5000 lines, 150 files, 3am
- Split 1: lines < 1000? No
→ Path length: 1 (anomaly!)
```

### Features for Anomaly Detection

We'll use 4 features to detect anomalies:

1. **lines_changed**: Total lines added + deleted
2. **files_changed**: Number of files modified
3. **time_of_day**: Hour when commit was made (0-23)
4. **churn_ratio**: Proportion of code that was modified

**Why these features?**
- **lines_changed**: Large commits are unusual
- **files_changed**: Touching many files is unusual
- **time_of_day**: Late night commits are unusual
- **churn_ratio**: High churn indicates instability

### Severity Mapping

We'll map anomaly scores to severity levels:

- **CRITICAL**: Score ≥ 0.9 (extremely unusual)
- **HIGH**: Score ≥ 0.7 (very unusual)
- **MEDIUM**: Score ≥ 0.5 (somewhat unusual)
- **LOW**: Score < 0.5 (slightly unusual)

```python
from pydantic import BaseModel, Field
from typing import Literal


class AnomalyDetectRequest(BaseModel):
    """
    Request schema for anomaly detection.

    This defines the data needed to detect if a commit is anomalous.

    Attributes:
        commit_id: Unique identifier for the commit
        features: Dictionary containing commit characteristics
    """
    commit_id: str = Field(
        ...,
        description="Unique commit identifier (SHA)",
        min_length=1,
        max_length=100
    )
    features: dict = Field(
        ...,
        description="Commit features for anomaly detection"
    )

    class Config:
        """Pydantic configuration"""
        json_schema_extra = {
            "example": {
                "commit_id": "abc123def456",
                "features": {
                    "lines_changed": 1500,
                    "files_changed": 45,
                    "time_of_day": 14,
                    "churn_ratio": 0.65
                }
            }
        }


class AnomalyDetectionResult(BaseModel):
    """
    Response schema for anomaly detection.

    This defines what the API returns after analyzing a commit.

    Attributes:
        is_anomaly: Whether the commit is classified as anomalous
        anomaly_score: Anomaly score from 0 (normal) to 1 (anomalous)
        severity: Severity level based on the score
        model_version: Version of the model used
    """
    is_anomaly: bool = Field(
        ...,
        description="Whether commit is classified as anomalous"
    )
    anomaly_score: float = Field(
        ...,
        ge=0.0,
        le=1.0,
        description="Anomaly score (0=normal, 1=anomalous)"
    )
    severity: Literal["LOW", "MEDIUM", "HIGH", "CRITICAL"] = Field(
        ...,
        description="Severity level of the anomaly"
    )
    model_version: str = Field(
        default="1.0.0",
        description="Model version used for detection"
    )

    class Config:
        """Pydantic configuration"""
        json_schema_extra = {
            "example": {
                "is_anomaly": True,
                "anomaly_score": 0.85,
                "severity": "HIGH",
                "model_version": "1.0.0"
            }
        }
```

**Understanding this code:**

1. **AnomalyDetectRequest**:
   - `commit_id`: Identifies which commit we're analyzing
   - `features`: Dictionary with the 4 features we need
   - Flexible structure allows adding more features later

2. **AnomalyDetectionResult**:
   - `is_anomaly`: Boolean for quick checks
   - `anomaly_score`: Continuous value for ranking
   - `severity`: Human-readable severity level
   - `Literal["LOW", "MEDIUM", "HIGH", "CRITICAL"]`: Only these 4 values allowed

3. **Why use dict for features?**:
   - Flexible: Easy to add new features
   - Simple: No need for nested models
   - Compatible: Works with numpy arrays

## Part 3: Implement Anomaly Detection Model

### Step 2: Create anomaly.py Model File

Create `app/models/anomaly.py`:

```python
from sklearn.ensemble import IsolationForest
import numpy as np
from typing import Dict, Tuple
import joblib
import os
import logging

logger = logging.getLogger(__name__)


class AnomalyDetector:
    """
    Isolation Forest-based anomaly detector for commits.

    This class wraps scikit-learn's IsolationForest to detect
    unusual commits based on their characteristics.

    The detector:
    1. Trains on normal commit data
    2. Learns what "normal" looks like
    3. Identifies commits that deviate from normal
    4. Maps scores to severity levels
    """

    def __init__(self, model_path: str = None):
        """
        Initialize the anomaly detector.

        Args:
            model_path: Path to saved model file (optional)
        """
        self.model_path = model_path
        self.model = None

        # Define feature names and their order
        self.feature_names = [
            'lines_changed',
            'files_changed',
            'time_of_day',
            'churn_ratio'
        ]

        # Try to load existing model
        if model_path and os.path.exists(model_path):
            self.load_model(model_path)
        else:
            # Initialize with default parameters
            self.model = IsolationForest(
                n_estimators=100,        # Number of trees
                contamination=0.1,       # Expected proportion of anomalies (10%)
                random_state=42,         # For reproducibility
                max_samples='auto'       # Automatic sample size
            )
            logger.info("Initialized new Isolation Forest model")

    def load_model(self, path: str):
        """
        Load a trained model from disk.

        Args:
            path: Path to the .pkl file

        Raises:
            Exception: If model cannot be loaded
        """
        try:
            self.model = joblib.load(path)
            logger.info(f"Loaded anomaly detection model from {path}")
        except Exception as e:
            logger.error(f"Failed to load model: {str(e)}")
            raise

    def save_model(self, path: str):
        """
        Save the trained model to disk.

        Args:
            path: Path where to save the .pkl file

        Raises:
            Exception: If model cannot be saved
        """
        try:
            # Create directory if it doesn't exist
            os.makedirs(os.path.dirname(path), exist_ok=True)

            # Save model using joblib
            joblib.dump(self.model, path)
            logger.info(f"Saved anomaly detection model to {path}")
        except Exception as e:
            logger.error(f"Failed to save model: {str(e)}")
            raise

    def _extract_features(self, features: Dict) -> np.ndarray:
        """
        Extract and order features from input dictionary.

        This ensures features are always in the same order that
        the model was trained on.

        Args:
            features: Dictionary with feature values

        Returns:
            numpy array with shape (1, 4)
        """
        feature_vector = []

        for feature_name in self.feature_names:
            # Get value or default to 0
            value = features.get(feature_name, 0)
            feature_vector.append(float(value))

        # Reshape to (1, 4) for single prediction
        return np.array(feature_vector).reshape(1, -1)

    def _map_severity(self, score: float) -> str:
        """
        Map anomaly score to severity level.

        Severity thresholds:
        - CRITICAL: score >= 0.9
        - HIGH: score >= 0.7
        - MEDIUM: score >= 0.5
        - LOW: score < 0.5

        Args:
            score: Anomaly score (0-1)

        Returns:
            Severity level string
        """
        if score >= 0.9:
            return "CRITICAL"
        elif score >= 0.7:
            return "HIGH"
        elif score >= 0.5:
            return "MEDIUM"
        else:
            return "LOW"

    def detect(self, features: Dict) -> Tuple[bool, float, str]:
        """
        Detect if a commit is anomalous.

        This is the main method for anomaly detection.

        Args:
            features: Dictionary containing:
                - lines_changed: int
                - files_changed: int
                - time_of_day: int (0-23)
                - churn_ratio: float (0-1)

        Returns:
            Tuple of (is_anomaly, anomaly_score, severity)

        Raises:
            ValueError: If model is not initialized or trained
        """
        if self.model is None:
            raise ValueError("Model not initialized or loaded")

        # Extract features in correct order
        X = self._extract_features(features)

        # Predict: -1 for anomaly, 1 for normal
        prediction = self.model.predict(X)[0]
        is_anomaly = (prediction == -1)

        # Get anomaly score
        # decision_function returns negative values for anomalies
        # More negative = more anomalous
        raw_score = self.model.decision_function(X)[0]

        # Normalize score to 0-1 range
        # Typical range is approximately [-0.5, 0.5]
        # We want: more negative = higher score
        normalized_score = max(0.0, min(1.0, 0.5 - raw_score))

        # Map to severity level
        severity = self._map_severity(normalized_score)

        logger.debug(
            f"Anomaly detection: is_anomaly={is_anomaly}, "
            f"score={normalized_score:.3f}, severity={severity}"
        )

        return is_anomaly, normalized_score, severity

    def train(self, X: np.ndarray):
        """
        Train the anomaly detection model.

        The model learns what "normal" commits look like from the
        training data. It doesn't need labels - it's unsupervised.

        Args:
            X: Training data with shape (n_samples, 4)
               Each row is [lines_changed, files_changed, time_of_day, churn_ratio]

        Raises:
            ValueError: If X has wrong shape
        """
        if X.shape[1] != len(self.feature_names):
            raise ValueError(
                f"Expected {len(self.feature_names)} features, "
                f"got {X.shape[1]}"
            )

        if self.model is None:
            self.model = IsolationForest(
                n_estimators=100,
                contamination=0.1,
                random_state=42
            )

        logger.info(f"Training anomaly detector on {X.shape[0]} samples")
        self.model.fit(X)
        logger.info("Training complete")


# Global detector instance (will be initialized when model is loaded)
detector = None


def get_detector(model_path: str = None) -> AnomalyDetector:
    """
    Get or create global detector instance.

    This implements the singleton pattern - only one detector
    instance exists and is reused.

    Args:
        model_path: Path to model file

    Returns:
        AnomalyDetector instance
    """
    global detector
    if detector is None:
        detector = AnomalyDetector(model_path)
    return detector
```

**Understanding this code:**

1. **IsolationForest Parameters**:
   - `n_estimators=100`: Build 100 trees (more = better but slower)
   - `contamination=0.1`: Expect 10% of data to be anomalies
   - `random_state=42`: Makes results reproducible
   - `max_samples='auto'`: Automatically choose sample size

2. **_extract_features()**:
   - Ensures features are in correct order
   - Handles missing features (defaults to 0)
   - Reshapes to (1, 4) for single prediction

3. **_map_severity()**:
   - Simple threshold-based mapping
   - Easy to adjust thresholds
   - Human-readable severity levels

4. **detect()**:
   - Main public method
   - Returns tuple for efficiency
   - Normalizes score to 0-1 range

5. **Score Normalization**:
   - `decision_function()` returns raw scores
   - Negative = anomaly, positive = normal
   - We convert to 0-1 where 1 = most anomalous

6. **train()**:
   - Unsupervised learning (no labels needed)
   - Learns from normal data
   - Validates input shape

7. **Singleton Pattern**:
   - `get_detector()` ensures one instance
   - Efficient (model loaded once)
   - Thread-safe for FastAPI

### Step 3: Create train_anomaly.py Script

Create `scripts/train_anomaly.py`:

```python
import numpy as np
import pandas as pd
from app.models.anomaly import AnomalyDetector
import logging
import sys
import os

# Add parent directory to path so we can import app modules
sys.path.insert(0, os.path.abspath(os.path.join(os.path.dirname(__file__), '..')))

logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)


def generate_synthetic_data(n_samples: int = 1000) -> np.ndarray:
    """
    Generate synthetic commit data for training.

    This creates realistic commit data with:
    - 90% normal commits
    - 10% anomalous commits

    Args:
        n_samples: Total number of samples to generate

    Returns:
        numpy array with shape (n_samples, 4)
    """
    np.random.seed(42)  # For reproducibility

    # Calculate split
    n_normal = int(n_samples * 0.9)
    n_anomaly = n_samples - n_normal

    logger.info(f"Generating {n_normal} normal and {n_anomaly} anomalous commits")

    # Generate NORMAL commits
    # Normal commits have:
    # - 50-200 lines changed (mean=100, std=50)
    # - 1-10 files changed (Poisson with lambda=5)
    # - Commits during work hours (8am-6pm)
    # - Low churn ratio (beta distribution)

    normal_lines = np.random.normal(100, 50, n_normal)
    normal_lines = np.clip(normal_lines, 10, 500)  # Reasonable bounds

    normal_files = np.random.poisson(5, n_normal)
    normal_files = np.clip(normal_files, 1, 20)

    normal_time = np.random.randint(8, 18, n_normal)  # 8am to 6pm

    normal_churn = np.random.beta(2, 5, n_normal)  # Low churn

    # Generate ANOMALOUS commits
    # Anomalous commits have:
    # - 500-2000 lines changed (much larger)
    # - 20-100 files changed (many files)
    # - Commits at odd hours (late night/early morning)
    # - High churn ratio

    anomaly_lines = np.random.normal(1000, 500, n_anomaly)
    anomaly_lines = np.clip(anomaly_lines, 500, 5000)

    anomaly_files = np.random.poisson(50, n_anomaly)
    anomaly_files = np.clip(anomaly_files, 20, 200)

    # Odd hours: 0-3am or 11pm-midnight
    anomaly_time = np.random.choice([0, 1, 2, 3, 22, 23], n_anomaly)

    anomaly_churn = np.random.beta(5, 2, n_anomaly)  # High churn

    # Combine normal and anomalous data
    lines_changed = np.concatenate([normal_lines, anomaly_lines])
    files_changed = np.concatenate([normal_files, anomaly_files])
    time_of_day = np.concatenate([normal_time, anomaly_time])
    churn_ratio = np.concatenate([normal_churn, anomaly_churn])

    # Create feature matrix
    X = np.column_stack([
        lines_changed,
        files_changed,
        time_of_day,
        churn_ratio
    ])

    return X


def analyze_data(X: np.ndarray):
    """
    Analyze and display statistics about the training data.

    Args:
        X: Training data array
    """
    df = pd.DataFrame(X, columns=[
        'lines_changed',
        'files_changed',
        'time_of_day',
        'churn_ratio'
    ])

    logger.info("\nTraining Data Statistics:")
    logger.info(f"\n{df.describe()}")

    logger.info("\nFeature Correlations:")
    logger.info(f"\n{df.corr()}")


def test_model(detector: AnomalyDetector):
    """
    Test the trained model with sample commits.

    Args:
        detector: Trained AnomalyDetector instance
    """
    logger.info("\nTesting model with sample commits:")

    test_samples = [
        {
            "name": "Normal commit (small change during work hours)",
            "features": {
                "lines_changed": 100,
                "files_changed": 5,
                "time_of_day": 14,
                "churn_ratio": 0.3
            }
        },
        {
            "name": "Anomaly (massive change)",
            "features": {
                "lines_changed": 5000,
                "files_changed": 150,
                "time_of_day": 2,
                "churn_ratio": 0.9
            }
        },
        {
            "name": "Anomaly (late night commit)",
            "features": {
                "lines_changed": 200,
                "files_changed": 10,
                "time_of_day": 3,
                "churn_ratio": 0.4
            }
        },
        {
            "name": "Normal commit (moderate change)",
            "features": {
                "lines_changed": 150,
                "files_changed": 8,
                "time_of_day": 10,
                "churn_ratio": 0.25
            }
        },
        {
            "name": "Anomaly (high churn)",
            "features": {
                "lines_changed": 300,
                "files_changed": 15,
                "time_of_day": 15,
                "churn_ratio": 0.95
            }
        }
    ]

    for i, sample in enumerate(test_samples, 1):
        is_anomaly, score, severity = detector.detect(sample["features"])

        logger.info(f"\nSample {i}: {sample['name']}")
        logger.info(f"  Features: {sample['features']}")
        logger.info(f"  Is Anomaly: {is_anomaly}")
        logger.info(f"  Score: {score:.3f}")
        logger.info(f"  Severity: {severity}")


def main():
    """
    Main training script.

    This script:
    1. Generates synthetic training data
    2. Analyzes the data
    3. Trains the Isolation Forest model
    4. Tests the model
    5. Saves the model to disk
    """
    logger.info("=" * 60)
    logger.info("Anomaly Detection Model Training")
    logger.info("=" * 60)

    # Step 1: Generate training data
    logger.info("\nStep 1: Generating synthetic training data...")
    X_train = generate_synthetic_data(n_samples=1000)
    logger.info(f"Generated {X_train.shape[0]} samples with {X_train.shape[1]} features")

    # Step 2: Analyze data
    logger.info("\nStep 2: Analyzing training data...")
    analyze_data(X_train)

    # Step 3: Initialize and train detector
    logger.info("\nStep 3: Training Isolation Forest model...")
    detector = AnomalyDetector()
    detector.train(X_train)
    logger.info("Training complete!")

    # Step 4: Test model
    logger.info("\nStep 4: Testing trained model...")
    test_model(detector)

    # Step 5: Save model
    logger.info("\nStep 5: Saving model to disk...")
    model_path = "data/models/anomaly_model.pkl"
    detector.save_model(model_path)
    logger.info(f"Model saved to {model_path}")

    # Verify model can be loaded
    logger.info("\nStep 6: Verifying model can be loaded...")
    loaded_detector = AnomalyDetector(model_path)
    logger.info("Model loaded successfully!")

    # Test loaded model
    test_features = {
        "lines_changed": 100,
        "files_changed": 5,
        "time_of_day": 14,
        "churn_ratio": 0.3
    }
    is_anomaly, score, severity = loaded_detector.detect(test_features)
    logger.info(f"Test prediction: is_anomaly={is_anomaly}, score={score:.3f}")

    logger.info("\n" + "=" * 60)
    logger.info("Training Complete!")
    logger.info("=" * 60)
    logger.info(f"\nModel saved to: {model_path}")
    logger.info("You can now use this model in the API service.")


if __name__ == "__main__":
    main()
```

**Understanding this code:**

1. **generate_synthetic_data()**:

   - `np.random.randint(8, 18)`: Work hours only
   - `np.random.beta(2, 5)`: Low churn ratio

3. **Anomalous Commits**:
   - Much larger line changes (1000 ± 500)
   - Many more files (50 ± Poisson)
   - Odd hours (late night/early morning)
   - High churn ratio

4. **analyze_data()**:
   - Uses pandas for nice statistics

5. **test_model()**:
   - Tests with 5 different scenarios
   - Includes both normal and anomalous cases
   - Logs detailed results

6. **main()**:
   - Orchestrates the entire training process
   - Clear steps with logging
   - Verifies model can be saved and loaded

```python
    prefix="/api/ml/anomaly",
    tags=["anomaly"]
)


def get_anomaly_detector(settings: Settings = Depends(get_settings)) -> AnomalyDetector:
    """
    Dependency to get anomaly detector instance.

    This is called by FastAPI's dependency injection system.
    It ensures the detector is initialized with the correct model path.

    Args:
        settings: Application settings (injected by FastAPI)

    Returns:
        AnomalyDetector instance
    """
    return get_detector(settings.anomaly_model_path)


@router.post("/detect", response_model=AnomalyDetectionResult)
async def detect_anomaly(
    request: AnomalyDetectRequest,
    detector: AnomalyDetector = Depends(get_anomaly_detector),
    settings: Settings = Depends(get_settings)
):
    """
    Detect if a commit is anomalous based on its features.

    This endpoint analyzes commit characteristics and determines if
    the commit deviates significantly from normal patterns.

    Features analyzed:
    - lines_changed: Total lines added + deleted
    - files_changed: Number of files modified
    - time_of_day: Hour when commit was made (0-23)
    - churn_ratio: Proportion of code modified (0-1)

    Args:
        request: AnomalyDetectRequest with commit_id and features
        detector: AnomalyDetector instance (injected)
        settings: Application settings (injected)

    Returns:
        AnomalyDetectionResult with anomaly status, score, and severity

    Raises:
        HTTPException: If detection fails

    Example:
        POST /api/ml/anomaly/detect
        {
            "commit_id": "abc123",
            "features": {
                "lines_changed": 5000,
                "files_changed": 150,
                "time_of_day": 2,
                "churn_ratio": 0.9
            }
        }

        Response:
        {
            "is_anomaly": true,
            "anomaly_score": 0.92,
            "severity": "CRITICAL",
            "model_version": "1.0.0"
        }
    """
    try:
        # Detect anomaly
        is_anomaly, score, severity = detector.detect(request.features)

        logger.info(
            f"Anomaly detection for commit {request.commit_id}: "
            f"is_anomaly={is_anomaly}, score={score:.3f}, severity={severity}"
        )

        return AnomalyDetectionResult(
            is_anomaly=is_anomaly,
            anomaly_score=score,
            severity=severity,
            model_version=settings.anomaly_model_version
        )

    except ValueError as e:
        # Model not loaded or invalid input
        logger.error(f"Validation error: {str(e)}")
        raise HTTPException(
            status_code=400,
            detail=f"Invalid request: {str(e)}"
        )
    except Exception as e:
        # Unexpected error
        logger.error(f"Anomaly detection error: {str(e)}", exc_info=True)
        raise HTTPException(
            status_code=500,
            detail=f"Anomaly detection failed: {str(e)}"
        )
```

2. **get_anomaly_detector()**:
   - Dependency function
   - FastAPI calls this automatically
   - Returns detector with correct model path
   - Ensures model is loaded

3. **detect_anomaly()**:
   - Main endpoint
   - Takes `AnomalyDetectRequest`
   - Uses dependency injection for detector
   - Returns `AnomalyDetectionResult`

4. **Error Handling**:
   - `ValueError`: Invalid input (400 Bad Request)
   - `Exception`: Unexpected error (500 Internal Server Error)
   - Logs all errors with context

5. **Logging**:
   - Info level for successful detections
   - Error level for failures
   - Includes commit ID for traceability

## Part 9: Understanding Isolation Forest

### How Isolation Forest Works

**Step 1: Build Random Trees**
```
For each tree:
  1. Randomly select a feature (e.g., lines_changed)
  2. Randomly select a split value
  3. Split data into two groups
  4. Repeat until each point is isolated
```

**Step 2: Calculate Path Length**
```
Path length = number of splits needed to isolate a point

Normal point:
  Root → Split 1 → Split 2 → Split 3 → Split 4 → Split 5 → Isolated
  Path length: 5

Anomalous point:
  Root → Split 1 → Isolated
  Path length: 1
```

**Step 3: Average Across Trees**
```
Average path length across all 100 trees
Shorter average = more anomalous
```

**Step 4: Convert to Score**
```
Raw score = average path length
Normalized score = 0 (normal) to 1 (anomalous)
```

### Why It Works

1. **Anomalies are rare**: Few points in that region
2. **Anomalies are different**: Far from normal points
3. **Easy to isolate**: Fewer splits needed
4. **Unsupervised**: No labels needed

## Part 12: Understanding the Complete Flow

### Training Flow

```
1. Generate Synthetic Data
   ↓
2. Create Feature Matrix (n_samples × 4)
   ↓
3. Train Isolation Forest
   - Build 100 random trees
   - Learn normal patterns
   ↓
4. Save Model to Disk (.pkl file)
   ↓
5. Model Ready for Use
```

### Prediction Flow

```
Client Request
    ↓
POST /api/ml/anomaly/detect
    ↓
FastAPI Router (anomaly.py)
    ↓
detect_anomaly() function
    ↓
Pydantic validates AnomalyDetectRequest
    ↓
AnomalyDetector.detect()
    ↓
├─ _extract_features() → Order features correctly
├─ model.predict() → Get -1 or 1
├─ model.decision_function() → Get raw score
├─ Normalize score to 0-1
└─ _map_severity() → Map to severity level
    ↓
AnomalyDetectionResult created
    ↓
Pydantic validates response
    ↓
JSON response to client
```

### Data Flow Example

**Input:**
```json
{
  "commit_id": "abc123",
  "features": {
    "lines_changed": 5000,
    "files_changed": 150,
    "time_of_day": 2,
    "churn_ratio": 0.9
  }
}
```

**Processing:**
1. Extract features: [5000, 150, 2, 0.9]
2. Reshape to (1, 4): [[5000, 150, 2, 0.9]]
3. Predict: -1 (anomaly)
4. Decision function: -0.42
5. Normalize: 0.5 - (-0.42) = 0.92
6. Map severity: 0.92 → CRITICAL

**Output:**
```json
{
  "is_anomaly": true,
  "anomaly_score": 0.92,
  "severity": "CRITICAL",
  "model_version": "1.0.0"
}
```
